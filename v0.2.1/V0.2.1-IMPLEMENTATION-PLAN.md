## What We're Building

v0.2.1 adds three major language features on top of the existing v0.2.0 database infrastructure:

### 1. Lexer Token Pruning
Remove 22+ hardcoded tokens (`RightOf`, `Above`, `Below`, `TopLeft`, `Last`, etc.) so they can be used as identifiers.

### 2. Context-Aware Identifier Parsing
Parse prepositions and origin codes as contextual identifiers based on where they appear in the grammar.

### 3. Comptime Anchor Arithmetic Engine
Support mathematical expressions over entity anchor properties:
```hardware
at: [x: (Pad_A.center_x + Pad_B.center_x) / 2, y: Pad_A.center_y]
```

```rust
impl<'a> Parser<'a> {
    /// Check if current token is an identifier with specific value
    pub fn check_identifier(&self, expected: &str) -> bool {
        match self.peek() {
            Some(Token::Identifier(s)) => s == expected,
            _ => false,
        }
    }

    /// Consume identifier if it matches expected value
    pub fn match_identifier(&mut self, expected: &str) -> bool {
        if self.check_identifier(expected) {
            self.advance();
            true
        } else {
            false
        }
    }

    /// Expect specific contextual identifier or error
    pub fn expect_contextual_identifier(&mut self, expected: &str) -> Result<(), ParseError> {
        if self.match_identifier(expected) {
            Ok(())
        } else {
            Err(ParseError::ExpectedContextualKeyword {
                expected: expected.to_string(),
                found: format!("{:?}", self.peek()),
                span: self.current_span(),
            })
        }
    }
}
```

```rust
pub fn parse_primary_expression(&mut self) -> Result<Expression, ParseError> {
    match self.peek() {
        Some(Token::Identifier(name)) => {
            let entity = name.clone();
            self.advance();
            
            // Check for property access: Pad_A.right
            if self.match_token(Token::Dot) {
                let property = self.expect_identifier()?;
                return Ok(Expression::AnchorProperty {
                    entity,
                    property,
                    span: self.current_span(),
                });
            }
            
            Ok(Expression::Identifier(entity))
        }
        Some(Token::OpenParen) => {
            self.advance();
            let expr = self.parse_expression()?;
            self.expect_token(Token::CloseParen)?;
            Ok(Expression::Parenthesized(Box::new(expr)))
        }
        // ... other cases
    }
}

pub fn parse_binary_expression(&mut self) -> Result<Expression, ParseError> {
    let mut left = self.parse_primary_expression()?;
    
    while let Some(op_token) = self.peek() {
        let op = match op_token {
            Token::Plus => BinaryOperator::Add,
            Token::Hyphen => BinaryOperator::Subtract,
            Token::Asterisk => BinaryOperator::Multiply,
            Token::Slash => BinaryOperator::Divide,
            _ => break,
        };
        
        self.advance();
        let right = self.parse_primary_expression()?;
        
        left = Expression::BinaryOp {
            left: Box::new(left),
            op,
            right: Box::new(right),
            span: self.current_span(),
        };
    }
    
    Ok(left)
}
```

#### Step 3.4: Evaluate Anchor Expressions (4 hours)

**File**: `hwc-compiler/src/ir/anchor_arithmetic/evaluator.rs` (NEW)

**Purpose**: Evaluate expressions in topological order during placement

```rust
pub struct AnchorEvaluator<'a> {
    space: &'a HardwareSpace,
    placed_entities: FxHashMap<String, PlacedEntity>,
}

#[derive(Debug, Clone)]
pub struct PlacedEntity {
    pub bbox: BoundingBox,
    pub layer_z: i64,
}

impl<'a> AnchorEvaluator<'a> {
    /// Resolve anchor property to absolute picometer value
    pub fn resolve_anchor_property(
        &self,
        entity_name: &str,
        property: &str,
    ) -> Result<i64, EvaluationError> {
        let entity = self.placed_entities.get(entity_name)
            .ok_or_else(|| EvaluationError::EntityNotPlaced {
                entity: entity_name.into(),
            })?;
        
        match property {
            "left" => Ok(entity.bbox.min.x),
            "right" => Ok(entity.bbox.max.x),
            "bottom" => Ok(entity.bbox.min.y),
            "top" => Ok(entity.bbox.max.y),
            "center_x" => Ok((entity.bbox.min.x + entity.bbox.max.x) / 2),
            "center_y" => Ok((entity.bbox.min.y + entity.bbox.max.y) / 2),
            "width" => Ok(entity.bbox.max.x - entity.bbox.min.x),
            "height" => Ok(entity.bbox.max.y - entity.bbox.min.y),
            _ => Err(EvaluationError::UnknownProperty {
                property: property.into(),
            }),
        }
    }
    
    /// Evaluate expression to absolute picometer value
    pub fn evaluate_expression(&self, expr: &Expression) -> Result<i64, EvaluationError> {
        match expr {
            Expression::Integer(n) => Ok(*n),
            Expression::Measurement(m) => Ok(self.measurement_to_pm(m)?),
            Expression::AnchorProperty { entity, property, .. } => {
                self.resolve_anchor_property(entity, property)
            }
            Expression::BinaryOp { left, op, right, .. } => {
                let left_val = self.evaluate_expression(left)?;
                let right_val = self.evaluate_expression(right)?;
                match op {
                    BinaryOperator::Add => Ok(left_val + right_val),
                    BinaryOperator::Subtract => Ok(left_val - right_val),
                    BinaryOperator::Multiply => Ok(left_val * right_val),
                    BinaryOperator::Divide => Ok(left_val / right_val),
                }
            }
            // ... other cases
        }
    }
}
```
